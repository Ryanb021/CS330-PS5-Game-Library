
# CS330 Final Project

## PS5 Game Library & Player Management System

### Project Description

A database system that allows PS5 players to manage
their game collections, track gaming progress, earn
trophies, add friends, and view gaming activities.

### Project Goals

- Manage player accounts.
- Manage video game collections.
- Track game progress and trophies.
- Record game purchases.
- Manage friends and multiplayer sessions.
- Manage gaming notifications.

### Tools and Technologies

- SQL
- MySQL
- MySQL Workbench
- Visual Studio Code
- SQLTools
- SQLTools MySQL Driver
